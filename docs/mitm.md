# MitM 与 CA 证书

先说结论：**当前这套规则不需要 MitM。** 它全是域名级判定，`REJECT` 在网络层就把连接掐掉了，根本走不到解密那一步。

MitM 是为下面三件事准备的：

- 改写 HTTPS 响应体，比如去掉 App 内开屏广告、改返回的 JSON
- 按 URL 路径匹配规则，`DOMAIN-SUFFIX` 只看域名看不到 `/api/v2/xxx`
- 跑注入脚本

不做这三件事，装证书只会增加开销和故障面。

---

## 一、证书是设备级的，不是配置级的

这点最容易搞混。配置文件里的 `[Mitm]` 段只管三样：

```
hostname        哪些域名要解密（白名单）
ca-p12          证书本体，可以留空交给 App 管理
ca-passphrase   证书密码
```

**真正的安装和信任在 iOS 系统设置里，不在 Loon 里。** 换设备、抹机、重装都要重做一遍。

---

## 二、安装流程

iOS 上装 CA 要两步，很多人卡在第二步。

**第一步，生成并安装描述文件。**

Loon 首页或设置页找到证书管理，点生成 CA 证书，然后点安装。会跳到 Safari 下载一个描述文件。

下载完去「设置 → 通用 → VPN 与设备管理」，找到那个描述文件点安装，需要输锁屏密码。

**第二步，信任证书。**

这一步不做，证书装了也不生效，表现为所有 HTTPS 连接失败或直接不走 MitM。

「设置 → 通用 → 关于本机 → 证书信任设置」，找到 Loon 的证书，打开开关。

两步都完成后，Loon 里证书状态应该显示为已信任。

---

## 三、配置怎么写

```ini
[Mitm]
hostname = %APPEND% example.com, *.example.com
ca-p12 =
ca-passphrase =
skip-server-cert-verify = false
```

**`%APPEND%`** 表示追加到已有列表而不是覆盖。多个配置源共享证书时要用它。

**`ca-p12` 留空**，交给 App 内的证书管理。除非你要把证书固定进配置分发，否则不建议在这里填 base64。

**`hostname` 是最关键的**，支持 `*` 通配：

```
*.example.com        匹配所有子域，不含 example.com 本身
example.com          只匹配裸域名
*.example.com, example.com   两个都要写才对
```

**`skip-server-cert-verify = false`** 保持 false。设成 true 会让 Loon 不校验上游证书，等于关掉了中间人的基本保证。

---

## 四、边界

**越少越好。** `hostname` 每多一个域名，就多一条被解密的流量。写成 `*` 等于解密全部，性能和风险都不划算。

**证书固定会拦你。** 银行 App、支付类、部分游戏的 API 做了 SSL Pinning，发起连接时会校验证书链。你的 CA 不在它的白名单里，结果是连接直接失败，而不是走 MitM 后照常工作。这类域名不要放进 hostname。

本套规则里的 `10-direct.list` 收的就是这类，天然不会进 MitM 白名单。

**去广告的收益递减。** 域名级 `REJECT` 已经覆盖了大部分广告 SDK 的请求。剩下的是响应体里的广告字段，需要改写 JSON，收益小很多，但故障面大很多。

**证书过期要重装。** Loon 生成的 CA 有有效期，过期后所有 MitM 流量失败。表现是突然某个 App 打不开，而其他都正常，很难联想到证书。

---

## 五、排障

**装了证书但复写不生效**：先看第二步的信任开关有没有打开。再看 `hostname` 是否匹配，通配符 `*.a.com` 不包含 `a.com` 本身。

**某个 App 突然连不上，其他正常**：把它从 `hostname` 移除。大概率是证书固定。

**所有 HTTPS 都失败**：证书过期，或信任开关被关掉了。

**MitM 开了以后耗电明显上升**：`hostname` 范围太宽。收窄到实际需要改写的几个域名。

---

## 六、什么时候回来加

等你要做下面任一件事：

1. 用 Loon 的 Script 改写某个 App 的接口返回
2. 需要按路径拦截，比如只拦 `/ad/` 下的请求
3. 装需要 MitM 的插件

在那之前，保持 `[Mitm]` 段为空是正确状态。`check-conf.ps1` 会检查 `hostname` 和 `ca-p12` 的自洽：配了 hostname 没配证书会警告，配了证书没配 hostname 也会警告。
